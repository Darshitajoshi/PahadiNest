# 🏔️ PahadiNest

PahadiNest is an AI-powered homestay discovery platform for Uttarakhand. It helps travelers explore authentic mountain homestays with a secure and user-friendly experience.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication
- JWT
- bcrypt
- Google OAuth (Passport.js)

---

## ✨ Features

- User Registration & Login
- Google Sign In
- Protected Dashboard
- Add, Edit & Delete Homestays
- Secure Authentication
- Dark/Light Mode

---

## ⚙️ Backend Setup

```bash
cd backend
npm install
npm start
```
Backend runs on:

```
http://localhost:5000
```

---

## 💻 Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend runs on:

```
http://localhost:5173
```

---

## 📡 API Endpoints

### Authentication
- POST `/api/auth/register`
- POST `/api/auth/login`
- GET `/auth/google`

### Homestays
- GET `/api/homestays`
- POST `/api/homestays`
- PUT `/api/homestays/:id`
- DELETE `/api/homestays/:id`
