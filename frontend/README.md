# PahadiNest 🏔️

PahadiNest is an AI-powered homestay discovery web application designed to help travelers find peaceful mountain stays across Uttarakhand. Users can explore destinations, browse homestays, securely log in, and receive AI-powered travel assistance.

---

## 🌐 Live Demo

**Frontend:** https://pahadi-nest-mh5k.vercel.app

**Backend:** https://pahadinest-backend.onrender.com
---

## ✨ Features

- User Registration & Login
- Google OAuth Login
- AI Travel Assistant (Google Gemini API)
- Add, Edit, Delete Homestays (CRUD)
- Dashboard for Logged-in Users
- Responsive UI (Mobile, Tablet & Desktop)
- Modern React + Tailwind CSS Interface

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- JWT Authentication
- Passport.js (Google OAuth)
- Google Gemini API

## 🚀 Project Setup

Clone the repository:

```bash
git clone https://github.com/Darshitajoshi/PahadiNest.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```
